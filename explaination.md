In this lab, we used an ESP32 and an IR remote to control a 4-wheel robot. The IR receiver receives signals from the remote, and the ESP32 checks which button is pressed. The arrow buttons are used for robot movement: UP moves the robot forward, DOWN moves it backward, LEFT turns it left, and RIGHT turns it right. The OK button is used to stop the robot.
The robot speed can also be controlled using the remote. The * button decreases the speed by 5, and the # button increases the speed by 5. The numeric buttons can be used to enter a custom speed value, and button 0 confirms the speed. To make the robot safe and stable, the speed is limited between 0 and 100. After each command, the motors run based on the selected direction and current speed.
