This project is an IoT robot control system using an ESP32, MIT App Inventor, and a web radar display. The main purpose of this project is to control a robot using a mobile application and also allow the robot to work automatically using an ultrasonic sensor.
The system starts by initializing the ESP32, motors, servo motor, and ultrasonic sensor. After that, the ESP32 connects to WiFi and starts a web server. This web server receives commands from the MIT App Inventor mobile application. The robot can receive commands such as forward, backward, left, right, stop, speed control, servo control, manual mode, and automatic mode.
In Manual Mode, the robot is controlled directly by the user through the mobile app. When the user presses the movement buttons, the ESP32 receives the request and moves the robot based on the selected command. The speed slider is used to change the motor speed from 0 to 100. The servo slider is used to control the servo angle from 0 to 180 degrees. This allows the user to control both the robot movement and sensor direction manually.
In Automatic Mode, the robot can move by itself. The robot moves forward and uses the ultrasonic sensor to check the distance in front of it. If the robot detects an obstacle closer than 20 cm, it will stop first, wait for a short time, turn right about 90 degrees, and then continue moving forward. This helps the robot avoid obstacles without needing the user to control it manually.
The project also includes a web radar display. The radar uses the servo motor and ultrasonic sensor to scan the surrounding area. The radar data is shown on the web page so the user can see the angle and distance detected by the sensor. In manual mode, the radar angle follows the servo angle set by the user. In automatic mode, the radar scans from 0 to 180 degrees.
Overall, this project shows how an ESP32 can be used as a WiFi robot controller. It combines mobile app control, automatic obstacle avoidance, motor control, servo control, ultrasonic distance measurement, and web radar visualization in one system.
