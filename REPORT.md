The system starts by initializing the ESP32, Dabble app, motors, servo motor, and ultrasonic sensor. After initialization, the robot stays idle and does not move until a mode is selected. Pressing SELECT activates Manual Mode, where the joystick controls the robot movement and the buttons control the servo angle. Pressing START activates Automatic Mode, where the robot uses the ultrasonic sensor to detect obstacles. If an obstacle is closer than 25 cm, the robot stops and rotates left about 90 degrees before checking again. If the path is clear, the robot continues moving forward. The system continuously loops so the robot can keep checking mode buttons, joystick input, servo buttons, and ultrasonic readings.
